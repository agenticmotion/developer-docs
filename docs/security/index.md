# AZTA Security

Security controls for production AI-agent systems.

## Threat Areas

- Prompt injection
- Tool abuse
- Confused-deputy attacks
- Cross-tenant data exposure
- Credential and token exposure
- Unauthorized state mutation
- Runaway execution
- Insufficient runtime observability

AZTA addresses these threats by moving security-critical enforcement outside the model's reasoning loop.
